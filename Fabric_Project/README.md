📌 Microsoft Fabric Data Engineering Project
📖 Project Overview

This project demonstrates an end-to-end data engineering and analytics solution built using Microsoft Fabric. The main objective of this project is to understand how data is ingested, transformed, modeled, and deployed using modern Fabric components and best practices.

🎯 Project Objectives

To practice data loading and transformation in Microsoft Fabric

To design managed and external tables in Fabric Data Warehouse

To implement star schema for analytical workloads

To create semantic models and views for reporting and analysis

To understand Visual Query capabilities in Fabric

To implement CI/CD using Fabric Deployment Pipelines

🏗️ Project Components
🔹 Data Loading

Loaded structured data into Fabric Data Warehouse

Implemented efficient data ingestion techniques

🔹 Transformation

Applied data transformations for cleaning and preparing data

Ensured data quality and consistency

🔹 Managed & External Tables

Created managed tables for internal warehouse storage

Used external tables to reference external data sources

🔹 Data Warehouse & Views

Designed warehouse tables optimized for analytics

Created SQL views to simplify data access

🔹 Star Schema Design

Implemented Fact and Dimension tables

Optimized schema for reporting and BI use cases

🔹 Semantic Model

Built a semantic model to support business-friendly reporting

Enabled easy data consumption for Power BI

🔹 Visual Query in Fabric

Used Visual Query for low-code data exploration and transformations

🔹 CI/CD – Fabric Deployment Pipeline

Configured Fabric Deployment Pipelines

Automated deployment across environments (Dev → Test → Prod)

End-to-end data engineering lifecycle in Microsoft Fabric
